Functions overview:
- format_pvalue: changes from p-value number to "symbol"
- fun_ggSave.list: saves ggplots stored in list
- fun_ggSave: saves ggplots
- load_All_functions.r: loads all r-scripts/functions in a folder
- load_function: loads specified r-scripts/functions
- source_folder: loads all r-scripts/functions in a folder
- create_summary_table: calculates mean and sd per group. v2 has group input option
- Add_stat_test_dodge_v1: performs and adds p-values. works for t-test and wilcox
- import_process_data_v1: imports csv files and tidys up data
